# Raspberry Pi 5 (Cortex-A76, ARMv8.2), aarch64, Python 3.11+.
#
# Pi 3 / Pi 4 / CM4 are ARMv8.0 and cannot run these wheels: torch 2.10 and
# the prebuilt ExecuTorch runtime use ARMv8.2 dot-product (`sdot`) kernels and
# trap with SIGILL. Use requirements-pi-armv8.txt on those boards.
#
# ExecuTorch 1.1.0 is installed separately with --no-deps by setup_pi.sh.
# Its declared Linux dependency set includes coremltools, which has no
# aarch64 wheel; Arm's own runtime project excludes coremltools and pins the
# versions below. Installing the runtime support packages explicitly mirrors
# that working set without dragging in an x86-only package.
#
# The CPU index avoids pulling CUDA libraries onto the Pi. PyPI is kept as an
# extra index for packages that are not on the PyTorch index.
--index-url https://download.pytorch.org/whl/cpu
--extra-index-url https://pypi.org/simple
